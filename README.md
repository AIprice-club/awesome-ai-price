## 卡网比价

卡网（发卡网）是自动发货的虚拟商品网店，AI 卡网主要卖 ChatGPT、Claude、Gemini、Grok 的成品号、代充和 Team 车位。

- [AI价网](https://aiprice.club/)：收录 1,987 家卡网店铺、约 5 万条报价，每小时更新；按标准商品归类，标出成品号、代充、卡密、车位和质保。另有[全部卡网报价搜索](https://aiprice.club/market)和[每日价格变动](https://aiprice.club/price-changes)。
- [卡网大全 CardNav](https://cardnav.xyz/)：968 家商家、约 4.4 万件商品，另收录 489 个中转站和模型排行榜。
- [OpenPrice](https://openprice.cc/)：已收录 401 个渠道商的 AI 订阅比价。
- [BiWu.Ai](https://biwu.ai/)：280+ 卡网实时比价，支持中转 API 检测。
- [PriceAI](https://priceai.cc/)：卡网订阅与中转 API 比价。
- [PriceAI.io](https://priceai.io/)：约 2.1 万条报价、597 个活跃来源。
- [AI Price Memory](https://ai.pricememo.cn/)：约 1.1 万条报价，公开数据方法。
- [AI Club](https://aihuiyuan.club/)：466 个渠道的会员订阅比价。
- [别买贵](https://aiapiprice.com/)：440 家号商、每日更新。
- [水獭](https://shuita.xyz/)：129 家店铺、4,100 多件商品的 AI 会员订阅现货到手价。
- [RadarAI](https://radarai.cc/)：AI 低价卡网订阅比价。
- [PickAI](https://pickai.cc/)：低价卡网订阅比价。

## API 价格与中转站

- [AI价网 大模型 API 官方价格对比](https://aiprice.club/llm-gateway/official-api-price)：GPT、Claude、Gemini、DeepSeek 等官方 API 输入、输出、缓存价格和上下文长度。
- [AI价网 API 中转站价格榜](https://aiprice.club/llm-gateway)：4,000 多个中转站的模型价格与倍率。
